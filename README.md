# Hasib AI Agent

Mobile-first personal AI agent control panel.

## Features in this source snapshot
- Task inbox and status tracking
- Searchable persistent-memory notes UI
- Approval queue for sensitive actions
- Activity audit log and notification preferences
- Integrations management UI
- Supabase integration scaffolding

## Stack
React, TypeScript, TanStack Start/Router, Vite, Tailwind CSS, Supabase.

## Source transfer
This repository contains the source snapshot recovered from the Lovable project "Task Mind Dashboard" (project ID: c2640768-96ae-4103-911a-59b4394ea1ff).
Secret environment files (.env) are intentionally excluded. Configure required environment variables separately before production use.

## Development
Use the package manager and scripts defined in package.json. The intended checks are:
- `bun install`
- `bun run build`
- `bun run test`

Note: source transfer is not the same as a successful build or an installable Android APK. Those must be verified separately.
